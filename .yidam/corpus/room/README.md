# Room

A room is a place the player character can be, and everything an author composes is
composed relative to one. In this corpus an instance is a *room form* — a recognized way a
room can relate to the viewport and to the rooms around it — rather than a room from a
particular game. The distinction matters: this corpus is mapping what the vocabulary must
express, and "single-screen" is the thing a format has to have a word for.
