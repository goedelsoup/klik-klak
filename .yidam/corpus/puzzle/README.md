# Puzzle

A puzzle is a configuration of world state that holds progression closed until some set of
interactions opens it. It is the only thing in this vocabulary that spans interactions — no
single binding is a puzzle, and the gate is not any one of them — which is why it survives
as its own class despite having no authored content of its own. An instance is a recognized
puzzle pattern.
