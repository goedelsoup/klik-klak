# Hotspot

A hotspot is the part of a room a verb can be pointed at. In this corpus an instance is a
kind of targetable region, distinguished by how its presence is decided rather than by what
it depicts. The class exists because targeting is separable from everything else: a region
can be targetable while drawing nothing and holding no state, and an engine that fuses
targeting into its actor model has to reconcile that later.
