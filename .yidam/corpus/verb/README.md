# Verb

A verb is a member of the authoring vocabulary itself — the thing this corpus is counting.
An instance is an actual verb an author can offer the player, not a use of one. This is the
class the central question is asked about: a verb earns its place only if something cannot
be said without it, and a verb that no interaction exercises is a primitive with no
demonstrated need.
