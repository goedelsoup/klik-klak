# corpus

This corpus covers the authoring vocabulary of point-and-click adventure games — the
primitives an author works in (rooms, verbs, interactions, puzzles, conversations), the
engine subsystems and data formats that realize them, and the prior-art engines that
answered the same question differently. It is organized around one question: what is the
smallest set of authoring primitives that can express a classic point-and-click adventure
without escaping to a general-purpose scripting language?

Each file is one node. Nodes are small and focused — one concept, one relation, one artifact,
or one open question. Every node must have at least one outgoing link.

See [corpus conventions](../.vendor/prelude/guidelines/directories.md#corpus) for authoring rules,
the authored/generated node distinction, and `[verified]`/`[inference]`/`[open]` claim tags.
