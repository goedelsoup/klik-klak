# Cutscene

A cutscene is a sequence that runs without player input. This corpus seeds it as a class
under protest with itself: it may well prove to be an interaction whose response is long
and whose input is locked, and the class exists so that the collapse can be argued rather
than assumed. What would settle it is finding something a cutscene expresses that a
long-running interaction response cannot.

Class definition: [`cutscene.ont.yml`](../cutscene.ont.yml)
