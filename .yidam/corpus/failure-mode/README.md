# Failure Mode

A state an authored game or its content can enter that no author intended and the vocabulary
did not prevent. This is the evidence that a primitive is wrong: a vocabulary is measured by
what it makes impossible to write, and a failure mode is a demonstration that something
remained writable. `detectable_at` is the field that matters most — a state detectable at
authoring time is a gate somebody could build, and one detectable only at play is not.
