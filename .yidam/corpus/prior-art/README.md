# Prior Art

An existing adventure engine or authoring system, characterized by the vocabulary it gave
authors rather than by its feature list. A comparative claim needs a node to sit on: that
two engines answered one question differently is a statement about engines, and this is
where it goes.

**Read `source_standing` on every instance before citing it.** At genesis no source has
been retrieved for any of them and every claim is tagged `[inference]`. These systems are
widely described secondhand and the secondhand accounts disagree; recollection is not a
citation however confident it feels.
