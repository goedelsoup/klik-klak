# Interaction

An interaction is the binding of a verb to a target and, for a binary verb, to a second
object — together with what happens when it resolves. It is this corpus's hub and its UFO
relator: the response to "use crowbar with crate" belongs to neither the crowbar nor the
crate, and an engine that stores it on one of them has made a choice worth recording. An
instance here is a binding *shape*, since the shapes are what a vocabulary must provide.
