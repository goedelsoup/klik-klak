# crates

Rust crates implementing the domain computer — the retrieval, calculation, and feature
engineering capabilities that agents use to work with the corpus without loading it
wholesale into context.

See [crates conventions](../.yidam/.vendor/prelude/guidelines/directories.md#crates) for the three
capability types (connectors, calculators, feature engineering) and the index layer.

**The hazard first, because it is this repository's characteristic mistake.** The corpus's
subject *is* a Rust engine, so `crates/` risks being read as the engine itself. It is not.
Nothing here renders, plays, or runs a game. These crates *read* an authored artifact and
compute over it; an engine would execute one, and an engine's code is not this corpus's to
hold. A calculator that computes reachability is a research tool. A renderer is the object
under study.

**Zero dependencies, deliberately.** The shapes read here are small enough that a dependency
would be larger than the code it replaced, and CI for this repository is required to be
hermetic — a build that resolves a registry is a build whose colour depends on somebody
else's uptime. `crates/Cargo.toml` says so where a reader will meet it.

## What is here

| Crate | Kind | What it does |
|---|---|---|
| `game-format` | calculator | The `.game` model, its reader, and the **admission rule**: every operand must name something the game declares, of the right kind. |
| `reachability` | calculator | `.yidam/skills/reachability.md`, implemented — the reachable set, the stranded set, and the binding that stranded it, classified by cause. |
| `design-gate` | gate | The derivation check for `design/`, moved here from a shell script on the condition `.yidam/decisions/design-directory.yml` named. `cargo test -p design-gate` is the gate. |

```
cargo run -p reachability -- design/specimen/lighthouse.game
```

**The vocabulary-coverage calculator is still expected and still unwritten.** Given the
`interaction` nodes and the `verb` vocabulary they draw on, report which verbs no
interaction exercises and which interactions need a verb the vocabulary does not declare.
`design/specimen/README.md` computed both lists by hand once, over a specimen rather than
over the corpus — and whether those are one computation with two inputs or two different
questions is `[open]` in `.yidam/skills/vocabulary-coverage.md`. Writing it before that is
settled would answer the wrong question quickly.

No connectors are planned. The sources this domain draws on are engine documentation and
source releases, which are read once and cited, not polled — a connector against a manual
that has not changed since 1997 would be a refresh loop over a fixed file.
